# Lipsync Studio

Automatic lip-syncing for 2D animation.

[Live Demo](lipsyncstudio.netlify.app)

## Usage
1. Drag and drop your character folder (must contain a.png, i.png, u.png, e.png, o.png, rest.png).
2. Upload audio and input transcript.
3. Fine-tune on the timeline and export.

## Development
Built with Vanilla JS and Web Audio API. 
For singing voice recognition, please use dry acapella tracks for better accuracy.
